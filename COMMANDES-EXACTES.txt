📌 MÉTHODE 2 : COMMANDES MANUELLES
═══════════════════════════════════════════════════════════════

ÉTAPE 1 : Vérifier Node.js (dans un terminal Windows normal)
─────────────────────────────────────────────────────────────
node --version
npm --version

Si ces commandes fonctionnent, continuez. Sinon, installez Node.js.

─────────────────────────────────────────────────────────────
ÉTAPE 2 : Ouvrir le premier terminal - BACKEND
─────────────────────────────────────────────────────────────

cd C:\Users\sselm\OneDrive\Desktop\NosqlProject\backend

npm install

npm run dev

→ Laissez ce terminal ouvert, il doit continuer à tourner
→ Vous devriez voir "MongoDB Connected" et "Server running on port 5000"

─────────────────────────────────────────────────────────────
ÉTAPE 3 : Ouvrir un DEUXIÈME terminal - FRONTEND
─────────────────────────────────────────────────────────────

cd C:\Users\sselm\OneDrive\Desktop\NosqlProject\frontend

npm install

npm start

→ Laissez ce terminal ouvert aussi
→ Votre navigateur s'ouvrira automatiquement sur http://localhost:3000
