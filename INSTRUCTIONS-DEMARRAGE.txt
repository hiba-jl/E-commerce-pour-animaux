═══════════════════════════════════════════════════════════════
  GUIDE DE DÉMARRAGE RAPIDE - APPLICATION E-COMMERCE
═══════════════════════════════════════════════════════════════

📌 AVANT DE COMMENCER :
   1. Assurez-vous que MongoDB est installé et démarré
   2. Vérifiez que Node.js est installé (version 14+)

═══════════════════════════════════════════════════════════════
  MÉTHODE 1 : UTILISER LES SCRIPTS .BAT (FACILE)
═══════════════════════════════════════════════════════════════

1. Vérifiez que MongoDB est démarré (voir ci-dessous)

2. Double-cliquez sur : start-backend.bat
   → Le backend démarrera dans une fenêtre

3. Double-cliquez sur : start-frontend.bat
   → Le frontend démarrera dans une autre fenêtre
   → Votre navigateur s'ouvrira automatiquement

✅ L'application sera accessible sur http://localhost:3000

═══════════════════════════════════════════════════════════════
  MÉTHODE 2 : LANCEMENT MANUEL (RECOMMANDÉ)
═══════════════════════════════════════════════════════════════

ÉTAPE 1 : Vérifier MongoDB

   Option A - MongoDB Local :
   → Si MongoDB est installé comme service, il démarre automatiquement
   → Sinon, ouvrez un terminal et tapez : mongod

   Option B - MongoDB Atlas (Cloud) :
   → Créez un compte sur https://www.mongodb.com/cloud/atlas
   → Modifiez backend/.env et remplacez MONGODB_URI par votre URL

ÉTAPE 2 : Configurer le Backend

   1. Ouvrez un terminal/PowerShell
   2. Naviguez vers le dossier backend :
      cd backend

   3. Installez les dépendances (première fois seulement) :
      npm install

   4. Vérifiez le fichier .env existe :
      - S'il n'existe pas, créez-le avec :
        PORT=5000
        MONGODB_URI=mongodb://localhost:27017/ecommerce
        JWT_SECRET=your-super-secret-jwt-key-change-this-in-production-123456
        NODE_ENV=development

ÉTAPE 3 : Lancer le Backend

   Dans le terminal (toujours dans backend/) :
   npm run dev

   ✅ Vous devriez voir :
      "MongoDB Connected"
      "Server running on port 5000"

ÉTAPE 4 : Lancer le Frontend (NOUVEAU TERMINAL)

   1. Ouvrez un NOUVEAU terminal/PowerShell
   2. Naviguez vers le dossier frontend :
      cd frontend

   3. Installez les dépendances (première fois seulement) :
      npm install

   4. Lancez le frontend :
      npm start

   ✅ Le navigateur s'ouvrira sur http://localhost:3000

═══════════════════════════════════════════════════════════════
  PREMIÈRE UTILISATION
═══════════════════════════════════════════════════════════════

1. Créez un compte utilisateur via l'interface web
2. Pour créer un admin, voir SETUP.md ou utilisez MongoDB :
   
   Dans MongoDB Compass ou mongo shell :
   use ecommerce
   db.users.updateOne(
     { email: "votre-email@example.com" },
     { $set: { role: "admin" } }
   )

3. Déconnectez-vous et reconnectez-vous pour voir l'onglet Admin

═══════════════════════════════════════════════════════════════
  DÉPANNAGE
═══════════════════════════════════════════════════════════════

❌ "Cannot find module"
   → Supprimez node_modules et réinstallez : npm install

❌ "MongoDB connection error"
   → Vérifiez que MongoDB est démarré
   → Vérifiez l'URL dans backend/.env

❌ "Port already in use"
   → Fermez l'autre application utilisant le port 5000 ou 3000

❌ Frontend ne se connecte pas au backend
   → Vérifiez que le backend tourne sur le port 5000
   → Vérifiez que le proxy dans frontend/package.json est correct
