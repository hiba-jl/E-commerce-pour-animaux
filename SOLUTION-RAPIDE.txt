❌ Erreur : npm ne fonctionne pas dans PowerShell

✅ SOLUTION SIMPLE : Utiliser CMD au lieu de PowerShell
═══════════════════════════════════════════════════════════════

OPTION 1 : UTILISER CMD (PLUS SIMPLE)
───────────────────────────────────────────────────────────────

1. Fermez PowerShell
2. Ouvrez CMD (Invite de commandes) :
   - Appuyez sur Win + R
   - Tapez : cmd
   - Appuyez sur Entrée

3. Dans CMD, naviguez vers le dossier :
   cd C:\Users\sselm\OneDrive\Desktop\NosqlProject\frontend

4. Exécutez :
   npm install

✅ Ça fonctionnera sans problème dans CMD !

───────────────────────────────────────────────────────────────

OPTION 2 : ACTIVER LES SCRIPTS DANS POWERSHELL (ADMIN)
───────────────────────────────────────────────────────────────

1. Ouvrez PowerShell en ADMINISTRATEUR :
   - Win + X → "Windows PowerShell (Admin)"

2. Exécutez :
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope LocalMachine

3. Tapez "Y" pour confirmer

───────────────────────────────────────────────────────────────

OPTION 3 : CONTOURNER AVEC CMD DANS LE SCRIPT
───────────────────────────────────────────────────────────────

Modifiez les scripts .bat pour utiliser cmd au lieu de PowerShell.

immédiatement sans configuration supplémentaire.
