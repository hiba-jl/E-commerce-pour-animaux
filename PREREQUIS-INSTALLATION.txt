═══════════════════════════════════════════════════════════════
  PRÉREQUIS AVANT DE LANCER L'APPLICATION
═══════════════════════════════════════════════════════════════

✅ VOUS DEVEZ AVOIR INSTALLÉ :
═══════════════════════════════════════════════════════════════

1. ✅ Node.js
   ───────────────────────────────────────────────────────────
   - Téléchargez depuis : https://nodejs.org/
   - Version LTS recommandée
   - npm est inclus automatiquement avec Node.js
   
   Vérification :
   node --version
   npm --version

2. ✅ MongoDB
   ───────────────────────────────────────────────────────────
   
   OPTION A - MongoDB Local (Recommandé pour débuter) :
   ───────────────────────────────────────────────────────────
   - Téléchargez depuis : https://www.mongodb.com/try/download/community
   - Choisissez Windows et MSI
   - Installez-le (cochez "Install MongoDB as a Service")
   - MongoDB démarrera automatiquement au démarrage de Windows
   
   OPTION B - MongoDB Atlas (Cloud - Gratuit) :
   ───────────────────────────────────────────────────────────
   - Créez un compte sur : https://www.mongodb.com/cloud/atlas
   - Créez un cluster gratuit (M0)
   - Obtenez votre chaîne de connexion
   - Modifiez backend/.env avec votre URL MongoDB Atlas
   
   Vérification (si MongoDB local) :
   - Ouvrez MongoDB Compass (inclus avec l'installation)
   - Ou vérifiez dans les Services Windows que MongoDB est démarré

═══════════════════════════════════════════════════════════════
📋 RÉSUMÉ - CE QUI EST NÉCESSAIRE
═══════════════════════════════════════════════════════════════

✅ OBLIGATOIRE :
   1. Node.js (https://nodejs.org/)
   2. MongoDB (local ou Atlas)
   
✅ AUTOMATIQUE :
   - npm (vient avec Node.js)
   - Toutes les autres dépendances s'installent avec npm install

═══════════════════════════════════════════════════════════════
🚀 APRÈS L'INSTALLATION DES PRÉREQUIS
═══════════════════════════════════════════════════════════════

1. Vérifiez que MongoDB est démarré
2. Lancez le backend (npm install puis npm run dev)
3. Lancez le frontend (npm install puis npm start)
